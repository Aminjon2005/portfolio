🎮 Block Blast Game

▶️ Play Now (Browser Mode)

📱 For Mobile Deployment:

  • Read README.md or README_RU.md
  • Follow steps in SETUP_GUIDE.md
  • Install Cordova: npm install -g cordova
  • Run: npm install
  • Add platform: cordova platform add android
  • Build: cordova build android

🔑 Appodeal Integration:

  • Register at Appodeal.com
  • Get your App Keys
  • Update keys in www/js/appodeal.js
  • Install plugin: cordova plugin add appodeal-cordova-plugin

🎯 Game Features:

  • ✅ Classic block puzzle gameplay (8x8 grid)
  • ✅ 30+ unique block shapes
  • ✅ Line clearing mechanics
  • ✅ Score tracking with best score
  • ✅ Modern, responsive UI
  • ✅ Touch-optimized for mobile
  • ✅ Appodeal ads integration ready
