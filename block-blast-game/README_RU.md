# Block Blast игра с интеграцией Appodeal

Мобильная головоломка, похожая на Block Blast, созданная с использованием HTML5, CSS3 и JavaScript, интегрированная с Appodeal для монетизации.

## 🎮 Особенности игры

- **Классический геймплей блочной головоломки**: Размещайте блоки на сетке 8x8
- **Очистка линий**: Очищайте полные ряды и столбцы для получения очков
- **Множество форм блоков**: Более 30 различных форм блоков
- **Система подсчета очков**: Отслеживайте текущий и лучший результат
- **Красивый интерфейс**: Современный, адаптивный дизайн с плавной анимацией
- **Готово для мобильных**: Оптимизировано для сенсорного управления на мобильных устройствах
- **Интеграция Appodeal**: Монетизация с помощью межстраничных баннеров и видеорекламы с вознаграждением

## 📱 Интеграция рекламы

Игра включает интеграцию Appodeal SDK с:
- **Баннерная реклама**: Отображается внизу экрана
- **Межстраничная реклама**: Показывается после завершения набора блоков или при окончании игры
- **Видеореклама с вознаграждением**: (Опционально) Может использоваться для предоставления бонусных очков или дополнительных ходов

## 🚀 Быстрый старт

### Для тестирования в браузере

1. Откройте `www/index.html` в веб-браузере
2. Игра будет работать без Appodeal в режиме браузера
3. Используйте перетаскивание мышью для размещения блоков

### Для мобильного развертывания

#### Предварительные требования

- Node.js (версия 14 или выше)
- Cordova CLI: `npm install -g cordova`
- Android SDK (для сборки под Android)
- Xcode (для сборки под iOS, только macOS)

#### Шаги установки

1. **Установите зависимости**
   ```bash
   cd block-blast-game
   npm install
   ```

2. **Настройте Appodeal**
   - Зарегистрируйтесь на [Appodeal](https://www.appodeal.com/)
   - Создайте приложение и получите ваши ключи приложения
   - Обновите `www/js/appodeal.js`:
     ```javascript
     APP_KEY_ANDROID: 'ваш_android_ключ',
     APP_KEY_IOS: 'ваш_ios_ключ',
     ```

3. **Добавьте плагин Appodeal**
   ```bash
   cordova plugin add https://github.com/appodeal/appodeal-cordova-plugin.git
   ```

4. **Добавьте платформы**
   ```bash
   cordova platform add android
   cordova platform add ios
   ```

5. **Соберите и запустите**
   
   Для Android:
   ```bash
   cordova run android
   ```
   
   Для iOS:
   ```bash
   cordova run ios
   ```

## 🎯 Как играть

1. **Перетаскивайте блоки** с нижней панели на сетку 8x8
2. **Размещайте блоки** стратегически, чтобы заполнить ряды или столбцы
3. **Очищайте линии**, полностью заполняя ряд или столбец
4. **Зарабатывайте очки** за размещение блоков и очистку линий
5. **Конец игры** наступает, когда вы не можете разместить ни один из доступных блоков

## 🔧 Конфигурация

### Ориентация
По умолчанию: Портретная (можно изменить в `config.xml`)

### Минимальные версии SDK
- Android: API 21 (Android 5.0)
- iOS: 11.0

### Настройки рекламы
Настройте поведение рекламы в `www/js/appodeal.js`:
- Установите `TESTING: true` для тестовой рекламы во время разработки
- Установите `TESTING: false` для производственной версии

## 📝 Настройка

### Изменить размер сетки
Отредактируйте `game.js`:
```javascript
gameBoard = new GameBoard(8); // Измените 8 на желаемый размер
```

### Добавить больше форм блоков
Отредактируйте `blocks.js` и добавьте новые формы в массив `BLOCK_SHAPES`

### Изменить цвета
Отредактируйте `blocks.js`, чтобы изменить цвета блоков в массиве `BLOCK_COLORS`

### Настроить частоту показа рекламы
Отредактируйте `main.js`, чтобы контролировать, когда показывается реклама

## 🐛 Устранение неполадок

### Appodeal не загружается
- Убедитесь, что плагин установлен правильно
- Проверьте правильность ваших ключей приложения
- Проверьте подключение к сети
- Проверьте консоль на наличие сообщений об ошибках

### Ошибки сборки
- Убедитесь, что все предварительные требования установлены
- Выполните `cordova clean` и пересоберите
- Проверьте версии платформ: `cordova platform ls`

### Cordova.js не найден (тестирование в браузере)
- Это нормально при тестировании в браузере
- Игра будет работать без функций Cordova
- Разверните на устройстве для полной функциональности
