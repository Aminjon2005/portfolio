## 🚀 Как начать использовать

### Вариант 1: Быстрое тестирование в браузере

Самый простой способ протестировать игру:

1. Откройте файл `QUICK_START.html` в браузере
2. Нажмите "Play Now"
3. Игра запустится в браузере (без Appodeal)

Или просто откройте `www/index.html` напрямую в браузере.

### Вариант 2: Полноценное мобильное приложение

Для создания реального мобильного приложения:

1. **Установите необходимое ПО:**
   ```bash
   # Node.js (скачайте с nodejs.org)
   # Затем установите Cordova
   npm install -g cordova
   ```

2. **Установите зависимости проекта:**
   ```bash
   cd block-blast-game
   npm install
   ```

3. **Зарегистрируйтесь в Appodeal:**
   - Перейдите на https://www.appodeal.com/
   - Создайте аккаунт и приложение
   - Получите ключи для Android и iOS

4. **Обновите ключи Appodeal:**
   
   Откройте `www/js/appodeal.js` и замените:
   ```javascript
   APP_KEY_ANDROID: 'YOUR_ANDROID_APP_KEY_HERE',
   APP_KEY_IOS: 'YOUR_IOS_APP_KEY_HERE',
   ```

5. **Добавьте платформу и соберите:**
   ```bash
   # Для Android
   cordova platform add android
   cordova build android
   
   # Для iOS (только на macOS)
   cordova platform add ios
   cordova build ios
   ```

Подробные инструкции смотрите в `SETUP_GUIDE.md`!

## 🎮 Как играть

1. **Начало игры:**
   - Игра начинается автоматически
   - На экране появляется пустая сетка 8x8
   - Внизу три случайных блока

2. **Размещение блоков:**
   - Перетащите блок на сетку
   - Блок должен полностью поместиться
   - Нельзя размещать на занятые клетки

3. **Очистка линий:**
   - Когда ряд или столбец полностью заполнены
   - Они автоматически очищаются
   - Вы получаете бонусные очки

4. **Подсчет очков:**
   - За каждый размещенный блок
   - Бонус за очистку линий
   - Больше линий = больше бонус

5. **Конец игры:**
   - Когда нельзя разместить ни один блок
   - Показывается ваш результат
   - Можно начать заново

## 💡 Где реклама будет показываться

### Баннерная реклама
- **Где:** Внизу экрана
- **Когда:** Постоянно во время игры
- **Как отключить:** `appodealManager.hideBanner()`

### Межстраничная реклама
- **Где:** Полноэкранная
- **Когда:** 
  - После размещения всех 3 блоков
  - При Game Over
- **Код:** `Appodeal.show(Appodeal.INTERSTITIAL)` в `main.js`

### Видеореклама с вознаграждением
- **Где:** Полноэкранная
- **Когда:** По желанию разработчика
- **Применение:** 
  - Получить дополнительные очки
  - Отменить ход
  - Получить подсказку
- **Код:** `appodealManager.showRewardedVideo(callback)`

## 🔧 Настройка и доработка

### Изменить размер сетки

В `www/js/game.js`, измените:
```javascript
gameBoard = new GameBoard(8); // 8x8 grid
```

На например:
```javascript
gameBoard = new GameBoard(10); // 10x10 grid
```

### Добавить новые формы блоков

В `www/js/blocks.js`, добавьте в массив `BLOCK_SHAPES`:
```javascript
// Пример: блок Т-образной формы
[[1, 1, 1],
 [0, 1, 0]]
```

### Изменить цвета блоков

В `www/js/blocks.js`, отредактируйте массив `BLOCK_COLORS`:
```javascript
const BLOCK_COLORS = [
    '#FF6B6B', // Красный
    '#4ECDC4', // Бирюзовый
    // Добавьте свои цвета...
];
```

### Изменить частоту показа рекламы

В `www/js/main.js`, функция `checkAllBlocksUsed()`:
```javascript
if (allUsed) {
    // Показывать рекламу каждый раз
    if (typeof Appodeal !== 'undefined') {
        Appodeal.show(Appodeal.INTERSTITIAL);
    }
}
```

Или добавьте счетчик для показа реже:
```javascript
let adCounter = 0;
if (allUsed) {
    adCounter++;
    if (adCounter % 3 === 0) { // Каждый 3-й раз
        Appodeal.show(Appodeal.INTERSTITIAL);
    }
}
```

## 🐛 Решение проблем

### Проблема: Игра не загружается в браузере
**Решение:** Убедитесь, что открываете `www/index.html` или `QUICK_START.html`

### Проблема: Appodeal не работает
**Решение:** 
- Appodeal работает только на реальных устройствах
- Проверьте правильность ключей
- Убедитесь, что плагин установлен

### Проблема: Блоки не перетаскиваются
**Решение:**
- Проверьте консоль браузера на ошибки
- Убедитесь, что все JS файлы загружены
- Попробуйте обновить страницу

### Проблема: Cordova build не работает
**Решение:**
- Проверьте установку Android SDK / Xcode
- Выполните `cordova clean`
- Проверьте версии: `cordova platform ls`
