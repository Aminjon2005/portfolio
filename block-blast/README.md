# Block Blast - Puzzle Game с интеграцией Appodeal

Современная HTML5 игра-головоломка в стиле Block Blast с полной интеграцией рекламной сети Appodeal.

## 🎮 Особенности игры

- **Классический геймплей Block Blast**: Размещайте блоки на сетке 10x10 и очищайте линии
- **Система прогрессии**: Уровни, очки, комбо-множители
- **Адаптивный дизайн**: Работает на всех устройствах
- **Звуковые эффекты**: Динамически генерируемые звуки
- **Анимации и эффекты**: Плавные переходы и частицы
- **Интеграция Appodeal**: Полная монетизация через рекламу

## 📱 Интеграция с Appodeal

### Типы рекламы
- **Межстраничная реклама**: Показывается при окончании игры и каждые 5 уровней
- **Видео с вознаграждением**: За шаринг результатов и дополнительные бонусы
- **Баннерная реклама**: В главном меню

### Настройка Appodeal

1. **Получите ключ приложения**:
   - Зарегистрируйтесь на [Appodeal.com](https://appodeal.com)
   - Создайте новое приложение
   - Скопируйте App Key

2. **Настройте ключ в коде**:
   ```javascript
   // В файле js/appodeal-integration.js
   const APP_KEY = 'YOUR_APP_KEY_HERE'; // Замените на ваш ключ
   ```

3. **Настройте типы рекламы**:
   ```javascript
   const adTypes = Appodeal.INTERSTITIAL | Appodeal.REWARDED_VIDEO | Appodeal.BANNER;
   ```

### Моменты показа рекламы

- **Межстраничная реклама**:
  - При окончании игры (через 2 секунды)
  - Каждые 5 уровней
  - При перезапуске игры (30% вероятность)

- **Видео с вознаграждением**:
  - При шаринге результатов (+100 очков)
  - Дополнительные жизни (можно добавить)

- **Баннеры**:
  - В главном меню (внизу экрана)
  - Скрываются во время игры

## 🎯 Игровая механика

### Размещение блоков
- Выберите блок из панели (3 блока доступно)
- Кликните на сетку для размещения
- Блок должен полностью помещаться в свободные ячейки

### Очистка линий
- Заполните полную горизонтальную или вертикальную линию
- Линия автоматически очистится
- Получите очки и увеличьте комбо-множитель

### Система очков
- **Базовые очки**: 10 за каждую ячейку блока × комбо
- **Бонус за линию**: 100 очков × количество линий × комбо
- **Множественные линии**: Дополнительный множитель

### Уровни
- Повышение каждые 1000+ очков
- Цель увеличивается на 50% каждый уровень
- Показ рекламы каждые 5 уровней
