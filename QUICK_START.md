# 🚀 Быстрый старт - Block Blast Game

## Запуск игры

### Вариант 1: Простой запуск (рекомендуется)
```bash
# Откройте терминал в папке с игрой
python3 server.py
```

### Вариант 2: Альтернативный сервер
```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен)
npx http-server -p 8000 -c-1
```

### Вариант 3: Прямое открытие
Просто откройте `block-blast-game.html` в браузере (некоторые функции могут не работать)

## Открытие игры

После запуска сервера откройте в браузере:
- **Локально**: http://localhost:8000/block-blast-game.html
- **Мобильно**: http://[ваш-ip]:8000/block-blast-game.html

## Настройка Appodeal

### 1. Получите ключ Appodeal
1. Зарегистрируйтесь на [appodeal.com](https://appodeal.com)
2. Создайте приложение
3. Скопируйте App Key

### 2. Вставьте ключ в код
Откройте файл `appodeal-integration.js` и найдите строку:
```javascript
this.appodealKey = 'YOUR_APPODEAL_APP_KEY';
```

Замените `YOUR_APPODEAL_APP_KEY` на ваш реальный ключ.

### 3. Настройте для продакшена
В том же файле измените:
```javascript
testMode: false, // Установите false для продакшена
```

## Возможные проблемы

### Игра не запускается
- Проверьте, что сервер запущен
- Убедитесь, что порт 8000 свободен
- Попробуйте другой браузер

### Реклама не показывается
- Проверьте подключение к интернету
- Убедитесь, что ключ Appodeal правильный
- Проверьте консоль браузера на ошибки

### Звуки не работают
- Разрешите воспроизведение звука в браузере
- Проверьте настройки звука в игре
- Убедитесь, что Web Audio API поддерживается

### Проблемы на мобильном
- Используйте HTTPS для продакшена
- Проверьте, что сервер доступен по IP
- Убедитесь, что порт не заблокирован
