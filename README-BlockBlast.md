# Block Blast Game с интеграцией Appodeal

## Описание проекта

Это полнофункциональная игра Block Blast, созданная на HTML5, CSS3 и JavaScript, с интеграцией Appodeal SDK для монетизации через рекламу.

## Особенности игры

### 🎮 Игровой процесс
- **Игровое поле 10x10** - классическое поле для размещения блоков
- **7 различных форм блоков** - I, L, T, O, S, Z, J блоки
- **Система очков и уровней** - прогрессия с увеличением сложности
- **Очистка линий** - заполненные строки и столбцы автоматически очищаются
- **Предпросмотр блоков** - видно следующие 2 блока

### 🎵 Звуковое сопровождение
- **Звуковые эффекты** - для всех игровых действий
- **Фоновая музыка** - приятная мелодия во время игры
- **Управление звуком** - возможность отключить звук и музыку
- **Адаптивная громкость** - настройка уровня громкости

### 📱 Мобильная оптимизация
- **Адаптивный дизайн** - работает на всех размерах экранов
- **Сенсорное управление** - поддержка касаний и свайпов
- **Оптимизация производительности** - для слабых устройств
- **Предотвращение зума** - стабильная работа на мобильных

### 💰 Монетизация Appodeal
- **Межстраничная реклама** - показывается при окончании игры
- **Наградная реклама** - за бонусные очки
- **Баннерная реклама** - в игровом интерфейсе
- **Fallback система** - работает даже без SDK

## Установка и настройка

### 1. Базовая настройка

1. Откройте `block-blast-game.html` в браузере
2. Игра готова к использованию без дополнительной настройки

### 2. Настройка Appodeal

#### Шаг 1: Регистрация в Appodeal
1. Перейдите на [appodeal.com](https://appodeal.com)
2. Создайте аккаунт
3. Создайте новое приложение
4. Получите App Key

#### Шаг 2: Настройка ключа
Откройте файл `appodeal-integration.js` и замените:

```javascript
this.appodealKey = 'YOUR_APPODEAL_APP_KEY'; // Замените на ваш ключ
```

#### Шаг 3: Настройка для продакшена
В файле `appodeal-integration.js` измените:

```javascript
testMode: false, // Установите false для продакшена
```

### 3. Настройка домена

Для работы с Appodeal необходимо:
1. Загрузить игру на веб-сервер
2. Добавить домен в настройки Appodeal
3. Настроить CORS если необходимо

## Использование

### Запуск игры
1. Откройте `block-blast-game.html` в браузере
2. Нажмите "Начать" для начала игры
3. Кликайте по клеткам для размещения блоков

### Управление
- **Клик/Касание** - размещение блока
- **Свайп** - дополнительные действия (в разработке)
- **Кнопки управления** - пауза, перезапуск, бонус

### Мобильное управление
- **Касание** - размещение блока
- **Свайп влево/вправо** - поворот блока
- **Свайп вверх/вниз** - быстрые действия
- **Кнопки** - дополнительные функции

## Настройка рекламы

### Типы рекламы

1. **Межстраничная реклама**
   - Показывается при окончании игры
   - Автоматическая предзагрузка
   - Fallback при ошибке загрузки

2. **Наградная реклама**
   - Кнопка "Бонус +100" очков
   - Выдача награды после просмотра
   - Уведомления о получении награды

3. **Баннерная реклама**
   - Встроена в игровой интерфейс
   - Адаптивный размер
   - Автоматическое обновление

### Настройка частоты показа

В файле `appodeal-integration.js` можно настроить:

```javascript
// Предзагрузка рекламы
preloadAds() {
    if (this.isInitialized) {
        Appodeal.cache('interstitial');
        Appodeal.cache('rewarded');
    }
}
```
